## 🎯 User Experience Flow

```
Page loads
    │
    ▼
💫  Ambient sparkles + floating hearts fill the screen
    │
    ▼
🎭  Character appears (bottom-left) with a pulsing "Click me to shoot love!" tooltip
    │
    ▼
🖱️  User clicks the character
    │
    ├──▶ 🎵  Romantic music starts automatically
    │
    └──▶ 💖  24 heart projectiles fire sequentially
              Each arcs across the screen with a glowing rose trail
              Lands with sparks · ring halos · gold stardust explosion
              Constructs one tile of the mosaic heart ❤️
    │
    ▼
❤️  Heart complete → pulses with a deep rose glow → rises upward
    │
    ▼
📸  "Our Love in Pictures" Polaroid gallery cascades into view
    Each card appears with a staggered fade + scale entrance
    │
    ▼
🔍  Click any photo → cinematic full-screen lightbox
📸  Click "Add Your Memory" → upload a custom photo with caption
```

## ✨ Features

| | |
|---|---|
| 🎵 **Romantic Background Music** | A floating glassmorphic music toggle button with a bouncing note animation. Music auto-starts on first interaction with the character. |
| 💖 **Click Sparkle Burst** | Clicking anywhere spawns a trio of rising hearts (💖 💕 ✨) that float upward and fade — the screen breathes romance everywhere. |
| 🏹 **Sequential Heart-Building Animation** | 24 projectiles fire one by one from the character, each arcing across the canvas and landing with sparks, ring halos, and gold stardust to build a mosaic heart. |
| 📸 **Polaroid Memory Gallery** | A staggered, cascading gallery of photo cards with a cinematic full-screen lightbox on click. |
| ➕ **Add Your Own Memory** | Upload a custom photo with a caption to add a new card to the gallery. |
| 📱 **Fully Responsive** | Built with pure CSS and vanilla JS — looks and works great on any screen size. |

## 🛠️ Getting Started

### Prerequisites

Just a modern web browser — no build tools, frameworks, or dependencies required.

### Theme Variables

```css
:root {
    --rose-deep:   #6b1238;   /* Darkest accent */
    --rose-mid:    #9e2a54;   /* Mid rose        */
    --rose-soft:   #cc5f85;   /* Soft highlight  */
    --gold-bright: #e8c47a;   /* Gold shimmer    */
}
```

### Run Locally

1. Clone this repository.
2. Open `index.html` in your browser — that's it.

### Deploy & Share

Host it anywhere static:

| Platform | How |
|---|---|
| **GitHub Pages** | Settings → Pages → Deploy from `main` branch |
| **Vercel** | Run `npx vercel` in the project folder |
